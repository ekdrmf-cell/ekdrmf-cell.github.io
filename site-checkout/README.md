# site-checkout — 서비스허브 공용 결제 백엔드

전자책ㆍ서비스ㆍ크로스노틱스가 함께 쓰는 결제 웹훅 처리기. 정적 사이트(GitHub Pages)와는 별도로
이 폴더만 Vercel에 독립 배포한다(무료 Hobby 플랜, 신규 비용 없음).

  코드 작성 완료.

- ❌ **아직 실제 포트원 계정으로 테스트한 적 없음** — 계획서 0단계(포트원 가입, 사업자등록 여부
  확인)가 사용자 액션으로 남아있어서 진짜 결제로 검증 불가능했음. 아래 "검증 안 된 가정" 참고.
- ❌ 크로스노틱스 리포트의 LLM 합성ㆍPDF 생성(`api/generate-report.py`)은 미구현 — 계획서
  3ㆍ4단계(Anthropic API 연동, report_kit.py) 완료 후 이어서 만들 것. 지금 크로스노틱스 결제가
  들어오면 계산까지는 되고 그 다음 단계에서 명시적 에러로 멈춤(무음 실패 아님).
- ❌ 전자책ㆍ서비스 자동발송도 미구현 — 기존 파일이 사용자 로컬 PC에만 있어 Vercel 함수가
  접근 못함. 이 상품들을 지금 이 시스템으로 옮길지 자체가 아직 사용자 결정 대기 중
  (계획서 9번 "남은 판단 사항" 참고). 그 전까지는 기존 계좌이체 방식을 그대로 쓸 것.

## 검증 안 된 가정 (다음 세션이 실제 포트원 테스트 결제로 반드시 확인)

`api/webhook.js` 상단 주석에 상세 기록돼있음 — 요약: 결제 조회 API 응답의 금액 필드 경로,
customData 필드명, Authorization 헤더 형식은 공식 문서로 100% 확정 못하고 합리적 추정으로
작성함. 첫 테스트 결제 때 실제 응답 JSON을 로그로 찍어서 이 가정들을 맞춰볼 것.

## 배포 순서 (0단계 사용자 액션 완료 후)

1. 포트원 가입(사업자등록 필요 여부 직접 확인) → 웹훅 시크릿ㆍAPI 시크릿 발급.
2. Gmail 앱 비밀번호 발급(무료, Google 계정 설정에서).
3. `npm install`
4. Vercel 계정(무료) 만들고 이 폴더를 프로젝트로 배포, `.env.example` 참고해 환경변수 등록.
5. 포트원 콘솔에 배포된 `/api/webhook` URL 등록.
6. 테스트 결제 1건으로 위 "검증 안 된 가정" 확인 후 코드 보정.
