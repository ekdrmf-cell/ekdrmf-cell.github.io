# 인스타 카드뉴스 초안 — 정부지원금 찾기 가이드 (9,900원)

## 슬라이드 구성 (6장)
1. (표지) "정부지원금, 어디서부터 찾아야 할지 막막하신가요?"
2. 기업마당·소상공인24·중소벤처24·지자체 사이트 — 4곳이나 되는데 다 따로 봐야 함
3. 사이트마다 성격이 다름 (통합검색용 / 정책자금용 / 지역특화용)
4. 어디부터 봐야 순서가 나오는지, 어떤 키워드로 검색해야 하는지가 핵심
5. 가이드에 포함된 것: 사이트별 상세 사용법, 용어사전, 실전사례 4개, 사업계획서 작성가이드
6. (마무리) "9,900원, 프로필 링크에서 확인하세요"

## 캡션
정부지원금 사이트가 4곳이나 되는데, 어디부터 봐야 할지 모르겠다는 분들 많더라고요.
사이트별로 뭘 봐야 하는지, 어떤 순서로 찾으면 되는지 정리했습니다.
자세한 건 프로필 링크 확인해주세요.
