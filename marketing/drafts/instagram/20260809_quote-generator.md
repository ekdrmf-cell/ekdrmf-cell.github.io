# 인스타 카드뉴스 초안 — 견적서 자동생성 템플릿 (서비스)

## 슬라이드 구성 (5장)
1. (표지) "견적서, 매번 손으로 다시 만드세요?"
2. 품목만 입력하면 견적서가 자동으로 완성되는 구글시트 템플릿
3. 설치 가이드까지 포함 — 코딩 몰라도 됨
4. 거래처가 많은 1인사업자·소상공인에게 특히 유용
5. (마무리) "지금 확인하기 — 프로필 링크"

## 캡션
견적서 매번 새로 만드시는 분들, 품목만 입력하면 자동으로 완성되는
구글시트 템플릿 만들었어요. 설치 가이드까지 같이 드립니다.
