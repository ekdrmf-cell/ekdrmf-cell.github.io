수동으로 확인할 때 생기는 문제

  1. 응답이 쌓일 때마다 시트를 열어 스크롤하며 눈으로 확인해야 함
  2. 선택형 문항은 옵션별 응답수를 손으로 세야 함
  3. 척도형(1~5점 등) 문항은 평균ㆍ분포를 별도로 계산해야 함
  4. 체크박스(복수선택) 문항은 응답이 쉼표로 이어진 텍스트 한 줄로

저장돼 옵션별로 나눠 세기가 번거로움

  1. 위 과정에서 시간이 지체되는 동안, 낮은 만족도 점수나 "환불"ㆍ"불만"

같은 위험 신호가 담긴 응답을 뒤늦게 발견하는 경우가 생김

문항 유형별 자동 집계 방식

  1. 선택형 문항 — 옵션별 응답수와 비율을 표로 자동 정리
  2. 척도형 문항 — 평균ㆍ최고ㆍ최저ㆍ점수별 분포를 자동 계산
  3. 체크박스(복수선택) 문항 — 쉼표로 이어진 응답을 자동으로 나눠

옵션별로 개별 집계

  1. 문항설정 시트에 "이 열은 선택형", "이 열은 척도형"처럼 한 번만

등록해두면, 폼 구성이 바뀌어도 설정만 다시 하면 재사용 가능
