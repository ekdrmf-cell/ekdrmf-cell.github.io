# 수익화허브

무자본으로 시작해서, 게임 · 서비스 · 전자책을 한 사이트에 모아 돈을 벌어보려는 실험 프로젝트입니다.

## 지금 있는 것

- **홈 화면** (`index.html`) — 게임, 서비스, 전자책을 한눈에 보여주는 첫 화면
- **게임 2종**
  - `games/2048/` — 숫자를 합쳐 2048을 만드는 퍼즐 게임
  - `games/runner/` — 점프해서 장애물을 피하는 러너 게임
  - "광고 보고 이어하기"(보상형 광고), "광고 제거"(유료 결제) 버튼은 있지만, 실제 애드센스/결제 연동 전까지는 껍데기(자리표시자)입니다.
- **서비스 페이지** (`services.html`)
  - **견적서 자동생성 템플릿(15,000원) — 실제로 판매 가능한 첫 상품.** `products/quote-generator/`에 실제 작동하는 구글시트+Apps Script 코드와 설치 가이드가 완성되어 있습니다.
  - 나머지 3개(자동화 템플릿 추가분, AI 상세페이지 제작, 소상공인 챗봇)는 아직 상품 자체는 없고, 관심 등록/문의만 받는 상태입니다.
- **전자책 페이지** (`ebooks.html`) — "소상공인 정부지원금 총정리 가이드"가 1순위 후보로 정해졌지만 아직 집필 전입니다. 출시 알림만 받습니다.
- **연락처 중앙 관리** (`js/config.js`) — 모든 문의/구매 버튼이 이 파일의 이메일 하나를 씁니다. 전용 채널로 바꿀 때 이 파일만 고치면 사이트 전체에 반영됩니다.

## 화면을 직접 보려면

이 폴더 안에서 터미널을 열고 아래 명령어를 입력하면 내 컴퓨터에서 미리 볼 수 있습니다.

```bash
python -m http.server 8765
```

그 다음 브라우저에서 `http://localhost:8765` 를 열면 됩니다.

## 새 게임 추가하는 법

`js/games-data.js` 파일에 게임 정보 한 줄만 추가하면 홈 화면과 게임 목록에 자동으로 나타납니다.

## 새 상품 추가하는 법

`products/` 아래에 상품별 폴더를 만들고(예: `products/quote-generator/`처럼), `services.html`에 카드 하나를 추가하면 됩니다. 카드의 버튼은 `contactMail('제목', '본문')` 형태로 `js/config.js`의 연락처를 통해 문의가 오게 만듭니다.
