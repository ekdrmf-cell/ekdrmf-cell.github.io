# 수익화허브

무자본으로 시작해서, 게임 · 서비스 · 전자책을 한 사이트에 모아 돈을 벌어보려는 실험 프로젝트입니다.

## 지금까지 만든 것

- **홈 화면** (`index.html`) — 게임, 서비스, 전자책을 한눈에 보여주는 첫 화면
- **게임 2종**
  - `games/2048/` — 숫자를 합쳐 2048을 만드는 퍼즐 게임
  - `games/runner/` — 점프해서 장애물을 피하는 러너 게임
  - 두 게임 모두 "광고 보고 이어하기"(보상형 광고), "광고 제거"(유료 결제) 버튼이 이미 들어있습니다. 다만 지금은 진짜 광고/결제가 아니라 껍데기(자리표시자)만 만들어둔 상태입니다.
- **서비스 페이지** (`services.html`) — 앞으로 팔 새 서비스 3가지 소개(자동화 템플릿 판매, AI 상세페이지 제작, 소상공인 챗봇 제작). 아직 실제로 판매를 시작한 건 아니고, 소개 페이지만 만들어둔 상태입니다.
- **전자책 페이지** (`ebooks.html`) — 어떤 기준으로 전자책을 고를지 설명하는 안내 페이지. 아직 실제 전자책은 없습니다.

## 화면을 직접 보려면

이 폴더 안에서 터미널을 열고 아래 명령어를 입력하면 내 컴퓨터에서 미리 볼 수 있습니다.

```bash
python -m http.server 8765
```

그 다음 브라우저에서 `http://localhost:8765` 를 열면 됩니다.

## 아직 진짜로 돈이 벌리지는 않습니다 — 앞으로 해야 할 일

1. **인터넷에 올리기(호스팅)**: 지금은 내 컴퓨터에서만 볼 수 있어요. Netlify, Vercel, GitHub Pages 같은 무료 서비스에 올려야 다른 사람들이 접속할 수 있습니다. (계정 생성은 본인이 직접 해야 합니다.)
2. **도메인**: `수익화허브.com` 같은 진짜 주소를 사려면 비용이 조금 듭니다(연 1~2만원). 무료 주소(예: `xxx.vercel.app`)로 먼저 시작해도 됩니다.
3. **광고 연결**: 구글 애드센스에 가입하고 심사를 통과해야 실제로 광고가 붙고 돈이 들어옵니다. 지금 게임에 있는 광고 버튼은 진짜 광고가 아니라 자리만 잡아둔 것입니다.
4. **결제 연결**: 서비스나 게임 유료 아이템을 실제로 팔려면 결제 수단을 연결해야 합니다. 처음에는 크몽/굼로드 같은 곳의 결제 링크를 걸어서 사업자등록 없이 시작하고, 나중에 매출이 생기면 직접 결제(PG) 연동으로 바꾸는 걸 추천합니다.
5. **서비스/전자책 실제 제작**: 지금 서비스·전자책 페이지는 "이런 걸 팔 예정입니다"라는 소개만 있고, 실제 상품은 아직 안 만들었습니다.

## 새 게임 추가하는 법

`js/games-data.js` 파일에 게임 정보 한 줄만 추가하면 홈 화면과 게임 목록에 자동으로 나타납니다.
