# 구글폼 응답 자동집계 + 조건부 알림 대시보드

구글폼으로 설문·신청·문의를 받고 있다면, 응답이 쌓일 때마다 스프레드시트를 일일이 스크롤하며
확인하고 계셨을 겁니다. 이 템플릿은 문항별 응답을 자동으로 집계해 표로 정리해주고, "낮은 만족도
점수"나 "환불·불만 같은 위험 키워드"가 담긴 응답이 들어오면 확인하러 가지 않아도 바로 이메일로
알려줍니다.

## 무엇이 자동화되나요

- 선택형 문항은 옵션별 응답수와 비율 막대를, 척도형 문항(1~5점 등)은 평균·최고·최저·점수별
  분포를 자동으로 계산해 "집계결과" 시트 한 장에 정리해줍니다.
- 지정해둔 척도 기준 이하 점수, 또는 주관식 답변에 위험 키워드가 포함된 새 응답이 들어오면
  즉시 관리자 이메일로 알림을 보냅니다(신청서의 낮은 만족도, CS 폼의 "환불" 언급 등).
- 위험으로 감지된 응답은 "알림이력" 시트에 시간·사유·응답 내용과 함께 자동으로 쌓입니다.
- 집계 대시보드를 PDF로 저장하거나, 이메일로 바로 받아볼 수 있습니다.

## 설치 방법 (5분)

1. 구글폼 편집 화면의 **응답** 탭에서 초록색 스프레드시트 아이콘을 눌러, 응답이 쌓이는
   스프레드시트를 엽니다(이미 폼과 연결돼 있으니 새로 만들 필요 없습니다).
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `문항설정` 시트 2개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `FormResponseDashboard.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는
   💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"응답 대시보드"**가 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후
   허용해주세요.

## 사용 방법

1. `문항설정` 시트에 응답 시트의 문항(열)을 한 줄씩 등록하고, 유형(선택형/척도형/주관식/제외)과
   위험감지 여부를 지정합니다.
2. 메뉴에서 **① 응답 집계 새로고침**을 누르면 "집계결과" 시트가 최신 내용으로 갱신됩니다.
3. **② 새 응답 위험 검사 + 알림**을 누르면, 지난번 검사 이후 들어온 새 응답만 훑어서 위험
   신호가 있으면 즉시 이메일을 보내고 이력을 남깁니다. 매번 손으로 누르기 번거로우면 아래
   "자동으로 매시간 실행하기"를 설정하세요.
4. **③ 집계 대시보드 PDF로 저장**, **④ 집계 요약 이메일로 보내기**로 언제든 현재 집계 상태를
   보관·공유할 수 있습니다.

## 자동으로 매시간 실행하기 (선택)

응답이 올 때마다 직접 메뉴를 누르지 않고 자동으로 위험 검사를 하고 싶다면:

1. Apps Script 편집기 왼쪽 시계 모양 **트리거** 메뉴를 클릭합니다.
2. 우측 하단 **트리거 추가**를 누릅니다.
3. 실행할 함수로 `checkNewResponsesAndAlert`를 선택합니다.
4. 이벤트 소스는 **시간 기반**, 시간 기반 트리거 유형은 **시간 타이머**를 선택하고
   원하는 주기(예: 1시간마다)를 지정한 뒤 저장합니다.
5. 요약 이메일도 매일 자동으로 받고 싶다면 같은 방식으로 `emailSummary` 함수를
   **일 단위 타이머**(예: 매일 오전 9시)로 하나 더 추가하면 됩니다.

## 자주 묻는 질문

**Q. 문항설정에 등록 안 한 열은 어떻게 되나요?**
A. 집계·감지에서 그냥 제외됩니다. 타임스탬프나 이메일 주소처럼 필요 없는 열은 등록하지 않거나
`제외`로 지정하면 됩니다.

**Q. "선택형"과 "체크박스(복수선택)" 문항도 되나요?**
A. 됩니다. 구글폼에서 체크박스 문항은 응답이 쉼표로 이어진 텍스트로 저장되는데, 이 템플릿이
쉼표 기준으로 나눠서 옵션별로 따로 집계합니다.

**Q. 폼이 여러 개인데 하나의 시트에서 같이 관리할 수 있나요?**
A. 안전하게 폼마다 별도 스프레드시트(별도 사본)로 관리하는 걸 권장합니다. 문항 구성이 다른
폼을 한 시트에 섞으면 "문항설정" 매칭이 꼬일 수 있습니다.

**Q. 위험 감지가 너무 자주(또는 너무 적게) 울려요.**
A. `설정` 시트의 위험점수기준·위험키워드를 조정하면 됩니다. 키워드는 쉼표로 여러 개를 등록할
수 있고, 등록한 단어 중 하나라도 포함되면 감지됩니다.

**Q. "마지막처리행"을 실수로 지웠어요.**
A. `설정` 시트에 "마지막처리행" 값을 1로 다시 넣으면, 다음 검사 때 처음부터 다시 훑습니다
(이미 지나간 응답도 다시 알림이 갈 수 있으니 필요할 때만 초기화하세요).
