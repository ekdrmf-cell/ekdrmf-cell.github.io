# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

이 템플릿은 **구글폼과 이미 연결된 응답 스프레드시트**를 그대로 사용합니다. 새 스프레드시트를
만들 필요 없이, 구글폼의 "응답 → 스프레드시트 만들기"로 생성된 파일에 아래 시트 4개를
추가로 만들어주면 됩니다. 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도
다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 사업체명 | (본인 사업체명 입력) |
| 응답시트이름 | (구글폼 응답이 쌓이는 시트 이름 — 보통 "설문지 응답 시트1") |
| 관리자이메일 | (위험 알림·요약 리포트를 받을 이메일) |
| 위험키워드 | (주관식 답변에서 감지할 단어, 쉼표로 구분. 예: 환불,불만,취소,실망,별로) |
| 위험점수기준 | (척도형 문항에서 이 점수 이하면 위험으로 판단. 예: 2) |
| 마지막처리행 | 1 (건드리지 마세요 — 스크립트가 자동으로 갱신합니다) |

- **응답시트이름**은 폼 편집 화면의 "응답" 탭 → 스프레드시트 아이콘을 눌렀을 때 자동 생성된
  시트의 실제 이름을 그대로 적으세요(구글이 자동으로 "설문지 응답 시트1"처럼 만들어줍니다).
- **위험점수기준**은 5점 척도든 10점 척도든 상관없이 "이 숫자 이하면 위험"으로 그대로
  비교하는 값입니다. 척도가 다르면 이 숫자를 척도에 맞게 조정하세요.

## 시트 2: `문항설정`

1행은 헤더, **실제 데이터는 2행부터** 입력합니다. 응답 시트의 열(문항) 하나당 한 줄씩
등록하세요.

| A열 (응답시트열이름) | B열 (문항유형) | C열 (위험감지) |
|---|---|---|
| 타임스탬프 | 제외 | N |
| 전반적으로 만족하셨나요? (1~5점) | 척도형 | Y |
| 어떤 상품을 구매하셨나요? | 선택형 | N |
| 불편했던 점이나 개선사항을 자유롭게 적어주세요 | 주관식 | Y |

- **A열(응답시트열이름)**은 응답 시트 1행(헤더)에 있는 문항 제목과 **글자 하나까지 정확히
  똑같아야** 합니다. 복사해서 붙여넣는 걸 권장합니다.
- **B열(문항유형)**은 다음 4가지 중 하나만 쓰세요:
  - `선택형` — 객관식/체크박스 문항(옵션별 응답수를 집계)
  - `척도형` — 1~5점, 1~10점 등 숫자 척도 문항(평균·최고·최저·위험 여부 판단)
  - `주관식` — 자유 서술형 문항(위험 키워드만 감지, 내용 요약은 하지 않음)
  - `제외` — 타임스탬프나 이메일 주소처럼 집계·감지가 필요 없는 열
- **C열(위험감지)**을 `Y`로 설정한 척도형 문항은 "위험점수기준" 이하일 때, 주관식 문항은
  "위험키워드"가 포함될 때 즉시 알림 대상이 됩니다. 감지가 필요 없으면 `N`으로 두세요.

## 시트 3: `집계결과`

**직접 만들 필요 없습니다.** 메뉴에서 "① 응답 집계 새로고침"을 실행하면 스크립트가 알아서
새로 만들고 매번 최신 내용으로 덮어씁니다. 문항별 응답수·평균·옵션별 비율 막대가 이 시트에
정리됩니다.

## 시트 4: `알림이력`

**직접 만들 필요 없습니다.** 첫 실행 시 스크립트가 자동으로 만듭니다. 위험으로 감지돼
알림을 보낸 응답의 시간·행 번호·감지 사유·응답 요약이 여기 쌓입니다.
