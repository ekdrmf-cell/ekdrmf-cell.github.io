# 학원 수강료 자동계산 + 수납관리 시트

수강생별 월 수강료와 입금 기록만 남기면, 이번달 완납/미납 여부를 자동으로 판정해서 원장님께 요약 이메일로, 학부모께는 납부 안내 이메일로 각각 알려주는 구글시트 템플릿입니다. 학원·공방·교습소처럼 매달 정해진 수강료를 받는 업종에 맞게 만들었습니다.

## 무엇이 자동화되나요

- 수강생별 월 수강료와 입금 기록만 쌓으면 이번달 완납/미납이 자동으로 계산됩니다.
- 미납 수강생은 수납현황 표에서 빨간색으로 자동 표시되고, 미납액도 함께 나옵니다.
- 원장님께 "이번달 미납자 몇 명" 요약 이메일을 보낼 수 있습니다(매달 자동 발송 설정도 가능).
- 미납 수강생의 학부모에게는 각자 다른 문구(학생 이름·미납액 포함)로 납부 안내 이메일을 한 번에 보낼 수 있습니다.
- 수납현황을 PDF로도 저장할 수 있습니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `수강생정보`, `수납기록`, `수납현황` 시트 4개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `AcademyTuitionTracker.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"수강료 자동관리"**가 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `수강생정보` 시트에 수강생별 월수강료·학부모이메일을 입력합니다.
2. 수강료를 받을 때마다 `수납기록` 시트에 한 줄씩 추가합니다(날짜·수강생명·금액).
3. 메뉴에서 **① 이번달 수납현황 새로고침**을 누르면 완납/미납이 색깔로 표시됩니다.
4. **② 수납현황 PDF로 저장**을 누르면 내 드라이브의 "수납현황_PDF" 폴더에 저장됩니다.
5. **③ 원장님에게 미납자 요약 이메일 발송**을 누르면 이번달 미납자 명단이 정리돼서 이메일로 갑니다.
6. **④ 미납 수강생 학부모에게 개별 납부안내 발송**을 누르면 학부모 이메일이 등록된 분들께 자동으로 안내 메일이 갑니다.
7. 매달 자동으로 미납 알림을 받고 싶다면 `템플릿_구조.md` 맨 아래 트리거 설정 방법을 따라하세요(5분).

## 자주 묻는 질문

**Q. 이번달인지는 어떻게 판단하나요?**
A. 시트를 여는 오늘 날짜가 속한 달(연·월)을 기준으로, 그 달에 들어온 수납기록만 합산합니다. 지난달 미납액이 이번달로 자동 이월되지는 않으니, 미납이 계속되면 매달 수동으로 확인해주세요.

**Q. 형제자매가 여러 명이라 수강료를 한 번에 몰아서 낼 때는 어떻게 하나요?**
A. `수납기록`에 학생별로 각각 한 줄씩 나눠서 입력해주세요(한 번의 이체를 여러 줄로 쪼개 기록해도 됩니다).

**Q. 카카오 알림톡으로 보낼 수는 없나요?**
A. 이 템플릿은 구글 계정만 있으면 바로 되는 이메일 발송까지만 기본 포함했습니다. 카카오 알림톡은 알리고·Solapi 같은 별도 유료 서비스 가입과 발신 프로필 등록이 필요해서, 필요하신 경우 별도로 연동을 고려해보시길 권합니다.
