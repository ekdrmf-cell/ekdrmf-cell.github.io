# 근로계약서 자동생성기

근로자 이름·연봉(또는 시급)·근무조건만 입력하면 고용노동부 표준근로계약서 양식에 맞춰 계약서를 자동으로 채워주는 구글시트 템플릿입니다. 채용할 때마다 계약서를 처음부터 새로 쓸 필요가 없습니다.

## 무엇이 자동화되나요

- 근로자 정보(이름·근무조건·임금 등)를 표에 입력하면 표준근로계약서 형식으로 자동 채워집니다.
- 시급으로 계약하는 경우, 입력한 시급이 최저임금보다 낮으면 자동으로 경고가 뜹니다.
- 근로자별로 계약서를 PDF로 저장하거나 이메일로 바로 보낼 수 있습니다.
- 정규직(기간의 정함이 없음)과 기간제(계약기간이 있음) 둘 다 지원합니다.

## 이 템플릿이 하는 일 vs 하지 않는 일 (꼭 읽어주세요)

이 템플릿은 **고용노동부가 공개한 표준근로계약서 양식의 빈칸을 자동으로 채워주는 서식 자동화 도구**입니다. 계약 조건이 법적으로 적절한지 판단해주는 법률 자문이 아닙니다.

- 외국인 근로자, 임원, 특수형태근로종사자, 건설일용직 등 특수한 고용 형태는 이 템플릿을 그대로 쓰지 마세요(별도 서식이 필요합니다).
- 계약 내용에 애매한 부분이 있으면 노무사 등 전문가의 검토를 받으시길 권합니다.
- 최저임금 등 법정 기준은 매년 바뀝니다. 이 템플릿은 2026년 기준 최저시급(10,320원)을 기준으로 경고를 표시하며, 매년 갱신이 필요합니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `근로자정보`, `계약서생성`, `계약서` 시트 4개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `EmploymentContractGenerator.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"근로계약서 자동생성"**이 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `근로자정보` 시트에 채용할 사람의 정보(근무조건·임금 등)를 입력합니다.
2. `계약서생성` 시트 B1에서 근로자를 선택합니다.
3. 메뉴에서 **① 계약서 생성/새로고침**을 누릅니다 → `계약서` 시트가 자동으로 채워집니다.
4. **② PDF로 저장**을 누르면 내 드라이브의 "근로계약서_PDF" 폴더에 저장됩니다.
5. **③ 이메일로 보내기**를 누르면 근로자 이메일로 바로 발송됩니다.
6. 근로기준법상 근로계약서는 사업주·근로자가 각 1부씩 보관해야 하니, 서명 후 근로자에게도 반드시 사본을 전달하세요.

## 자주 묻는 질문

**Q. 월급으로 계약하는데 최저임금 위반 여부를 확인해주지 않나요?**
A. 월급을 시급으로 환산하려면 소정근로시간에 따른 계산이 필요해서, 잘못된 계산으로 안내하는 위험을 피하려고 이 템플릿에서는 자동 확인하지 않습니다. [고용노동부 최저임금 모의계산기](https://www.moel.go.kr/miniWageMain.do)에서 직접 확인해보세요.

**Q. 매년 최저임금이 바뀌면 어떻게 하나요?**
A. `EmploymentContractGenerator.gs` 파일 상단의 `MIN_HOURLY_WAGE_2026` 숫자를 그 해의 최저시급으로 바꿔주시면 됩니다(Apps Script 편집기에서 직접 수정 가능).

**Q. 아르바이트생(단시간 근로자)에게도 쓸 수 있나요?**
A. 네, 소정근로시간·근무일을 실제 조건에 맞게 입력하면 됩니다. 다만 초단시간(주 15시간 미만) 근로자는 주휴수당·연차 적용이 달라지니 해당되는 경우 전문가 확인을 권합니다.
