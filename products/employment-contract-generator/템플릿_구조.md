# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 4개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 사업체명 | (본인 회사/매장명) |
| 대표자 | (대표자명) |
| 사업장주소 | (주소) |
| 담당자연락처 | (전화번호) |

## 시트 2: `근로자정보`

1행은 헤더로 두고, **실제 데이터는 2행부터** 입력합니다.

| 열 | 항목 | 예시 |
|---|---|---|
| A | 성명 | 박지훈 |
| B | 생년월일 | 1998-05-12 |
| C | 주소 | 서울시... |
| D | 연락처 | 010-0000-0000 |
| E | 이메일 | jihun@example.com |
| F | 근로시작일 | 2026-09-01 |
| G | 계약기간구분 | 정함없음 또는 정함있음 |
| H | 계약종료일 | (계약기간구분이 "정함있음"일 때만, 예: 2027-08-31) |
| I | 근무장소 | 본점 매장 |
| J | 업무내용 | 매장 판매 및 재고관리 |
| K | 소정근로일 | 주 5일(월~금) |
| L | 시업시각 | 09:00 |
| M | 종업시각 | 18:00 |
| N | 휴게시간 | 12:00~13:00 |
| O | 주휴일 | 매주 일요일 |
| P | 임금형태 | 월급 또는 시급 |
| Q | 임금액 | 2500000 |
| R | 상여금 | 없음 |
| S | 기타급여 | 없음 |
| T | 임금지급일 | 매월 25일 |
| U | 지급방법 | 근로자 명의 예금통장 입금 |

- **임금형태가 "시급"인 경우, 임금액이 2026년 최저시급(10,320원)보다 낮으면 계약서 생성 시 경고가 뜹니다.** 월급인 경우는 근로시간에 따라 환산이 필요해 이 템플릿에서 자동 확인하지 않으니, 아래 "최저임금 확인" 항목을 참고해 직접 확인하세요.
- G열(계약기간구분)은 반드시 `정함없음` 또는 `정함있음` 중 하나로 입력하세요.

## 시트 3: `계약서생성` (조작판)

| A열 | B열 |
|---|---|
| 근로자 선택 | (드롭다운으로 근로자정보의 이름 중 선택) |

**드롭다운 설정 방법(최초 1회)**: B1 셀 클릭 → [데이터 → 데이터 확인] → 조건 "범위의 값" → 범위에 `근로자정보!A2:A100` 입력 후 저장.

## 시트 4: `계약서`

- 이 시트는 **비워두세요**. 메뉴에서 "① 계약서 생성/새로고침"을 누르면 자동으로 채워집니다.

## 이 템플릿이 하는 일과 하지 않는 일 (반드시 읽어주세요)

이 템플릿은 **고용노동부가 공개한 표준근로계약서 양식의 빈칸을, 입력한 정보로 자동으로 채워주는 서식 자동화 도구**입니다. 법률 자문이 아니며, 계약 조건 자체(임금 수준이 적정한지, 특정 조항을 넣어야 하는지 등)를 판단해주지 않습니다.

- 외국인 근로자, 임원, 특수형태근로종사자, 건설일용직 등 **특수한 고용 형태**는 별도 서식이 필요할 수 있으니 이 템플릿을 그대로 쓰지 마세요.
- 계약 내용에 법적으로 애매한 부분이 있거나 분쟁 소지가 있다면 **노무사 등 전문가의 검토**를 받으시길 권합니다.
- 최저임금 등 법정 기준은 매년 바뀝니다. 생성된 계약서를 쓰기 전에 최신 기준을 다시 한번 확인하세요.

## 최저임금 확인 (선택)

월급으로 계약하는 경우, 시급으로 환산했을 때 최저임금 이상인지는 근로시간에 따라 계산 방식이 달라 이 템플릿에서 자동 확인하지 않습니다. [고용노동부 최저임금 모의계산기](https://www.moel.go.kr/miniWageMain.do)에서 직접 확인해보세요.

## 확인 체크리스트

- [ ] 시트 이름 4개(`설정`, `근로자정보`, `계약서생성`, `계약서`)가 정확히 일치하는가
- [ ] `근로자정보` 시트 F열(근로시작일)이 날짜 형식인가
- [ ] `계약서생성` 시트 B1에 드롭다운이 설정됐는가
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "근로계약서 자동생성" 메뉴가 보이는가
