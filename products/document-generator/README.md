# 거래명세서·발주서·견적서 통합 자동생성기

거래처를 한 번만 등록해두면, 같은 품목 표에서 견적서·거래명세서·발주서 세 가지 문서를 원하는 대로 골라 자동으로 만들어주는 구글시트 템플릿입니다. 매번 거래처 정보를 다시 입력할 필요가 없습니다.

## 무엇이 자동화되나요

- 거래처(고객·공급처)를 한 번 등록해두면 다음부터는 이름만 골라서 씁니다(주소·사업자번호를 매번 다시 칠 필요 없음).
- 같은 품목 표로 **견적서·거래명세서·발주서** 세 가지 문서를 드롭다운 선택만으로 바꿔가며 만들 수 있습니다.
- 소계·부가세·합계가 자동 계산됩니다.
- 발주서를 고르면 납품희망일·납품장소까지 자동으로 문서에 들어갑니다.
- 완성된 문서를 클릭 한 번으로 PDF 저장하거나 이메일로 바로 보낼 수 있습니다.

## 문서 3종의 차이

- **견적서**: 우리 회사가 공급자, 거래처가 공급받는 곳. "아래와 같이 견적합니다."
- **거래명세서**: 견적서와 방향은 같지만 이미 확정된 거래 내역을 통보하는 문서입니다. 거래처의 사업자번호도 함께 표시됩니다.
- **발주서**: 방향이 반대입니다. 우리 회사가 발주자, 거래처가 물건을 공급하는 곳으로 표시되고 납품희망일·납품장소가 추가됩니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `거래처마스터`, `항목입력`, `문서생성`, `문서` 시트 5개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `DocumentGenerator.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"문서 자동생성"**이 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `거래처마스터` 시트에 자주 거래하는 곳을 등록해둡니다.
2. `항목입력` 시트에 품목을 입력합니다.
3. `문서생성` 시트에서 거래처와 문서종류(견적서/거래명세서/발주서)를 고릅니다. 발주서라면 납품희망일·납품장소도 입력합니다.
4. 메뉴에서 **① 문서 생성/새로고침**을 누릅니다 → `문서` 시트가 자동으로 채워집니다.
5. **② PDF로 저장**을 누르면 내 드라이브의 "거래문서_PDF" 폴더에 저장됩니다.
6. **③ 이메일로 보내기**를 누르면 거래처 이메일이 자동으로 채워진 채로 바로 발송됩니다.

## 자주 묻는 질문

**Q. 거래처마스터에 없는 곳으로도 문서를 만들 수 있나요?**
A. 아니요, 먼저 `거래처마스터`에 한 줄 추가해야 `문서생성`의 드롭다운에 나타납니다. 일회성 거래처도 그때그때 한 줄 추가해서 쓰면 됩니다.

**Q. 기존에 판매 중인 "견적서 자동생성 템플릿"과 뭐가 다른가요?**
A. 견적서 자동생성 템플릿은 견적서 한 가지만, 매번 고객 정보를 새로 입력하는 방식입니다. 이 템플릿은 거래처 정보를 미리 저장해두고, 같은 곳과 반복 거래할 때 견적서·거래명세서·발주서를 오가며 쓸 수 있게 확장한 버전입니다.

**Q. 회사 로고를 넣고 싶어요.**
A. `문서` 시트는 자동 생성 후에도 일반 구글시트이므로, 생성 직후 이미지를 수동으로 삽입할 수 있습니다. 단, 메뉴 ①을 다시 누르면 지워지니 PDF 저장 직전에 넣는 걸 권장합니다.
