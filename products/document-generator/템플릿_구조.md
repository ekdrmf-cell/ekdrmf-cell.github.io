# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 5개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 회사명 | (본인 회사명 입력) |
| 사업자번호 | (000-00-00000) |
| 대표자 | (대표자명) |
| 연락처 | (전화번호) |
| 주소 | (주소) |
| 부가세율 | 0.1 |

- 이 정보는 견적서·거래명세서·발주서 어디에나 "우리 회사" 자리에 공통으로 들어갑니다.

## 시트 2: `거래처마스터`

1행은 헤더, **실제 데이터는 2행부터** 입력합니다. 한 번 등록해두면 문서를 만들 때마다 매번 다시 입력할 필요 없이 이름만 골라서 씁니다.

| A열 (거래처명) | B열 (사업자번호) | C열 (대표자) | D열 (연락처) | E열 (주소) | F열 (이메일) |
|---|---|---|---|---|---|
| 예: ㈜가나상사 | 111-22-33333 | 김가나 | 010-0000-0000 | 서울시... | ganamsa@example.com |

## 시트 3: `항목입력`

1행은 헤더로 두고, **실제 데이터는 2행부터** 입력합니다.

| A열 (품목) | B열 (규격) | C열 (수량) | D열 (단가) | E열 (비고) |
|---|---|---|---|---|
| 예: 홈페이지 제작 | 반응형 5페이지 | 1 | 800000 | |

- 견적서·거래명세서·발주서 모두 이 표에 입력한 항목을 그대로 사용합니다.

## 시트 4: `문서생성` (조작판)

| A열 | B열 |
|---|---|
| 거래처 선택 | (드롭다운으로 거래처마스터의 이름 중 선택) |
| 문서종류 선택 | (드롭다운으로 "견적서" / "거래명세서" / "발주서" 중 선택) |
| 납품희망일(발주서용) | (발주서를 만들 때만 입력, 예: 2026-08-15) |
| 납품장소(발주서용) | (발주서를 만들 때만 입력) |

**드롭다운 설정 방법(최초 1회)**:
1. B1 셀 클릭 → 상단 메뉴 [데이터 → 데이터 확인] → 조건 "범위의 값" → 범위에 `거래처마스터!A2:A100` 입력 후 저장.
2. B2 셀 클릭 → 상단 메뉴 [데이터 → 데이터 확인] → 조건 "목록에서 항목 선택" → 값에 `견적서,거래명세서,발주서` 입력 후 저장.

## 시트 5: `문서`

- 이 시트는 **비워두세요**. 메뉴에서 "① 문서 생성/새로고침"을 누르면 `문서생성` 시트에서 고른 거래처·문서종류에 맞춰 자동으로 채워집니다.

## 문서종류에 따라 달라지는 것

- **견적서**: 우리 회사가 공급자, 선택한 거래처가 공급받는 곳으로 표시됩니다.
- **거래명세서**: 견적서와 방향은 같지만, 이미 확정된 거래 내역을 통보하는 문구로 바뀌고 거래처의 사업자번호도 함께 표시됩니다.
- **발주서**: 반대로 선택한 거래처가 물건을 공급하는 곳, 우리 회사가 발주하는 곳으로 표시되고, 납품희망일·납품장소가 함께 나옵니다.

## 확인 체크리스트

- [ ] 시트 이름 5개(`설정`, `거래처마스터`, `항목입력`, `문서생성`, `문서`)가 정확히 일치하는가
- [ ] `거래처마스터` 시트 2행부터 거래처 정보가 들어있는가
- [ ] `문서생성` 시트 B1·B2에 드롭다운이 설정됐는가
- [ ] `항목입력` 시트 2행부터 데이터가 있는가
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "문서 자동생성" 메뉴가 보이는가
