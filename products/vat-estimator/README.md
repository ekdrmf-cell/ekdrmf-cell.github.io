# 매입매출장 자동정리 + 부가세 예상액 계산 시트

매출·매입 내역만 꾸준히 기록해두면, 원하는 기간(월별·분기별·반기별)의 매출세액·매입세액을 자동으로 집계해서 예상 부가세 납부액을 계산해주는 구글시트 템플릿입니다. 프리랜서·1인사업자(일반과세자)를 위해 만들었습니다.

## 무엇이 자동화되나요

- 매출·매입 내역을 표에 쌓기만 하면, 원하는 기간의 매출세액·매입세액이 자동으로 집계됩니다.
- 매입 건마다 "공제가능/공제불가"를 표시해두면 공제가능분만 반영해서 예상 납부(또는 환급)세액을 계산합니다.
- 공제여부를 표시하지 않은 매입 건이 있으면 집계에서 빠졌다고 경고해줘서 누락을 막아줍니다.
- 계산 결과를 PDF로 저장하거나, 세무사에게 바로 이메일로 넘길 수 있습니다.

## 이 템플릿이 하는 일 vs 하지 않는 일 (꼭 읽어주세요)

이 템플릿은 **선택한 기간의 매출·매입을 정리해서 "예상 납부세액"을 계산해주는 참고용 도구**입니다. 세금 신고를 대신 해주지 않습니다.

- 실제 부가가치세 신고서 작성·제출은 반드시 홈택스에서 직접 하거나 세무사에게 맡기세요.
- **일반과세자 전용입니다.** 간이과세자는 업종별 부가가치율을 적용하는 완전히 다른 계산 방식이라 이 템플릿을 쓰면 틀린 금액이 나옵니다.
- 매입세액 공제 가능 여부(접대비, 비영업용 승용차, 면세사업자 거래 등)는 사용자가 직접 판단해서 입력해야 합니다. 애매하면 "공제불가"로 넣고 세무사와 확인하세요.
- 계산 결과는 참고용 예상치이며, 실제 신고 시 금액이 달라질 수 있습니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `매입매출기록`, `집계기간선택`, `부가세현황` 시트 4개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `VatEstimator.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"부가세 예상액 계산"**이 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. 세금계산서·현금영수증·카드매입 내역을 확인할 때마다 `매입매출기록` 시트에 한 줄씩 추가합니다(매입은 공제가능/공제불가 직접 판단).
2. `집계기간선택` 시트에 확인하고 싶은 기간(시작일·종료일)을 입력합니다.
3. 메뉴에서 **① 부가세현황 계산/새로고침**을 누르면 예상 납부/환급세액이 계산됩니다.
4. **② 부가세현황 PDF로 저장**을 누르면 내 드라이브의 "부가세현황_PDF" 폴더에 저장됩니다.
5. **③ 이메일로 보내기**를 누르면 본인이나 세무사에게 바로 보낼 수 있습니다.

## 자주 묻는 질문

**Q. 매입세액 공제가능/불가를 어떻게 판단하나요?**
A. 접대비 관련 지출, 비영업용 소형승용차 구입·유지비, 면세사업자와의 거래, 사업과 무관한 지출, 적격증빙(세금계산서 등)이 없는 경우는 공제가 안 됩니다. 판단이 애매하면 "공제불가"로 넣는 게 안전합니다(과소공제가 과다공제보다 덜 위험합니다).

**Q. 신고 기간(1기/2기, 예정/확정)에 맞춰 자동으로 나눠주나요?**
A. 아니요, 이 템플릿은 사업자 형태(개인/법인)에 따라 신고 주기가 달라 혼란을 줄 수 있어서 자동으로 나누지 않습니다. 대신 원하는 기간을 직접 골라서 계산할 수 있게 만들었습니다 — 신고 기간에 맞춰 시작일·종료일을 직접 입력하면 됩니다.

**Q. 간이과세자인데 써도 되나요?**
A. 안 됩니다. 간이과세자는 업종별 부가가치율을 곱하는 완전히 다른 방식으로 세액을 계산합니다. 이 템플릿을 그대로 쓰면 틀린 금액이 나옵니다.
