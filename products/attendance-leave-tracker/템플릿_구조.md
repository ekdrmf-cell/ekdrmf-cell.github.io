# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 5개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 회사명 | (본인 회사명 입력) |
| 상시근로자5인이상 | 예 또는 아니오 |
| 통상시급 | 12000 |
| 소정근로시작 | 09:00 |
| 소정근로종료 | 18:00 |
| 소정근로시간 | 8 |
| 지각허용분 | 5 |
| 알림받을이메일 | (관리자가 요약 알림을 받을 이메일) |

- **상시근로자5인이상**: 연차유급휴가·연장근로 가산수당은 근로기준법상 상시근로자 5인 이상 사업장에만 적용됩니다. "아니오"로 두면 연차·가산수당 계산 없이 근태 기록만 정리합니다(아래 항목 참고).
- **지각허용분**: 소정근로시작 시각에서 몇 분까지는 지각으로 안 치는지(예: 5분이면 09:05까지는 정상 출근으로 인정).

## 시트 2: `직원정보`

1행은 헤더, **실제 데이터는 2행부터** 입력합니다.

| A열 (성명) | B열 (입사일) | C열 (이메일) |
|---|---|---|
| 예: 최유진 | 2025-03-01 | yujin@example.com |

## 시트 3: `근태기록`

1행은 헤더, **실제 데이터는 2행부터** 입력합니다. 매일 출퇴근할 때마다(또는 하루에 한 번씩 몰아서) 한 줄씩 추가하세요.

| A열 (날짜) | B열 (성명) | C열 (출근시각) | D열 (퇴근시각) | E열 (비고) |
|---|---|---|---|---|
| 예: 2026-08-03 | 최유진 | 09:03 | 18:40 | |
| 예: 2026-08-04 | 최유진 | | | 연차 |

- 출근·퇴근시각은 `09:00`처럼 시:분 형식의 **텍스트**로 입력하세요.
- 그날 출근시각·퇴근시각을 비워두고 E열(비고)에 `연차`, `공가`, `경조사` 등을 적으면 결근으로 처리되지 않습니다. 아무것도 안 적고 비워두면 결근으로 집계됩니다.

## 시트 4: `집계월선택` (조작판)

| A열 | B열 |
|---|---|
| 집계년월 | 2026-08 |

- `YYYY-MM` 형식으로 입력하세요. 이 달의 근태기록만 모아서 집계합니다.

## 시트 5: `근태현황`

- 이 시트는 **비워두세요**. 메뉴에서 "① 근태현황 생성/새로고침"을 누르면 자동으로 채워집니다.

## 연차·초과근무수당 계산 방식 (반드시 읽어주세요)

- **연차 발생일수**: 근로기준법 제60조 기준(입사 1년 미만은 매월 개근 시 1일씩, 1년 이상은 15일+계속근로 2년마다 1일 가산, 최대 25일)으로 계산한 **참고치**입니다. 이 공식은 "80% 이상 출근"을 가정하므로, 결근이 잦았던 달이 있으면 실제 발생일수와 다를 수 있습니다. **상시근로자 5인 미만 사업장은 연차유급휴가 규정 자체가 적용되지 않으므로, 설정 시트에서 "아니오"로 두면 이 계산을 아예 하지 않고 "해당없음"으로 표시합니다.**
- **초과근무시간**: 퇴근시각 − 출근시각 − 소정근로시간으로 단순 계산한 시간입니다.
- **초과근무수당(예상)**: 상시근로자 5인 이상일 때만 "초과근무시간 × 통상시급 × 1.5"로 계산합니다. 이는 연장근로 가산(50%)만 반영한 값이며, 야간근로(22시~06시)나 휴일근로가 겹치면 추가 가산이 붙을 수 있어 실제 금액과 다를 수 있습니다.
- 이 템플릿은 노무 자문이 아닙니다. 정확한 연차·수당 계산이 필요하면 노무사와 상담하세요.

## 확인 체크리스트

- [ ] 시트 이름 5개(`설정`, `직원정보`, `근태기록`, `집계월선택`, `근태현황`)가 정확히 일치하는가
- [ ] `설정` 시트에 상시근로자5인이상 여부가 정확히 입력됐는가
- [ ] `근태기록` 시트 출퇴근시각이 `09:00` 같은 시:분 텍스트 형식인가
- [ ] `집계월선택` 시트에 `YYYY-MM` 형식으로 입력했는가
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "근태·연차 자동관리" 메뉴가 보이는가
