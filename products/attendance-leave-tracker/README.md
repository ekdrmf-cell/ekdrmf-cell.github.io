# 근태관리 + 연차 자동집계 시트

출퇴근 시각만 기록하면 지각·조퇴·결근과 초과근무시간이 자동으로 집계되고, 근로기준법 기준 연차 발생일수·잔여일수까지 참고치로 계산해주는 구글시트 템플릿입니다. 관리자에게는 이상자 요약 이메일을, 직원 개개인에게는 근태 확인서를 자동으로 보낼 수 있습니다.

## 무엇이 자동화되나요

- 직원별 출퇴근 시각을 기록하면 지각·조퇴·결근이 자동으로 판정됩니다.
- 초과근무시간이 자동 계산되고, 상시근로자 5인 이상 사업장이면 예상 연장근로수당도 함께 나옵니다.
- 근로기준법 기준 연차 발생일수·사용일수(누적)·잔여일수를 참고치로 계산합니다.
- 지각이 잦거나 결근이 있는 직원은 근태현황 표에서 자동으로 표시됩니다.
- 관리자에게 이번달 근태 이상자 요약 이메일을 보낼 수 있고, 직원 각자에게는 본인의 근태·연차 확인서를 자동 발송할 수 있습니다.

## 이 템플릿이 하는 일 vs 하지 않는 일 (꼭 읽어주세요)

이 템플릿은 **노무 자문이 아니며, 근로기준법 표준 공식에 따른 참고치를 계산해주는 도구**입니다.

- 연차 발생일수는 "80% 이상 출근"을 가정한 계산이라, 결근이 잦았던 달이 있으면 실제와 다를 수 있습니다.
- 상시근로자 5인 미만 사업장은 연차유급휴가·연장근로 가산수당 규정 자체가 적용되지 않습니다. 설정 시트에서 "아니오"로 두면 이 항목은 계산하지 않고 "해당없음"으로 표시합니다.
- 초과근무수당은 연장근로 가산(50%)만 반영한 예상치이며, 야간근로·휴일근로가 겹치면 실제 금액은 더 높을 수 있습니다.
- 정확한 연차·수당 산정이 필요하면 노무사와 상담하세요.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `직원정보`, `근태기록`, `집계월선택`, `근태현황` 시트 5개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `AttendanceLeaveTracker.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"근태·연차 자동관리"**가 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `직원정보` 시트에 직원별 입사일·이메일을 입력합니다.
2. 매일(또는 몰아서) `근태기록` 시트에 출퇴근 시각을 입력합니다. 연차·공가를 쓴 날은 출퇴근시각을 비우고 비고에 "연차"처럼 적습니다.
3. `집계월선택` 시트에 확인하고 싶은 달(YYYY-MM)을 입력합니다.
4. 메뉴에서 **① 근태현황 생성/새로고침**을 누르면 지각·조퇴·결근·초과근무·연차 현황이 표로 나옵니다.
5. **② 근태현황 PDF로 저장**을 누르면 내 드라이브의 "근태현황_PDF" 폴더에 저장됩니다.
6. **③ 관리자에게 요약 이메일 발송**을 누르면 이상자(결근·잦은지각) 명단이 정리돼서 이메일로 갑니다.
7. **④ 직원별 근태확인서 개별 이메일 발송**을 누르면 이메일이 등록된 직원 각자에게 본인 근태·연차 확인서가 자동 발송됩니다.

## 자주 묻는 질문

**Q. 야간근무(교대제)도 되나요?**
A. 출퇴근시각을 그대로 입력하면 근무시간은 계산되지만, 퇴근시각이 자정을 넘어가는 경우(예: 22:00~06:00)는 시:분 텍스트 비교 방식이라 정확히 계산되지 않습니다. 교대제·야간근무가 많다면 이 템플릿보다 전문 근태관리 프로그램을 권합니다.

**Q. 연차 발생일수가 실제 회사 규정과 달라요.**
A. 이 템플릿은 근로기준법 표준 공식만 반영합니다. 회사 자체 규정(입사 즉시 연차 부여 등)이 다르면 참고치로만 쓰고 실제 지급은 회사 규정을 따르세요.

**Q. 상시근로자 수는 어떻게 세나요?**
A. 근로기준법상 "상시 사용하는 근로자 수"는 일정 기간의 평균으로 산정하는 등 별도 기준이 있습니다. 애매하면 노무사나 고용노동부에 확인 후 설정 시트에 입력하세요.
