# 견적서 자동생성 템플릿

항목만 입력하면 소계·부가세·합계까지 자동으로 계산해서 견적서를 만들어주고, PDF 저장과 이메일 발송까지 버튼 하나로 끝나는 구글시트 템플릿입니다.

## 무엇이 자동화되나요

- 항목(품목/규격/수량/단가)을 표에 입력하기만 하면 견적서 양식에 자동으로 채워집니다.
- 소계, 부가세, 합계를 직접 계산할 필요가 없습니다.
- 완성된 견적서를 클릭 한 번으로 PDF로 저장하거나, 바로 이메일로 보낼 수 있습니다.
- 매번 새 문서를 만들 필요 없이, 항목만 바꿔서 계속 재사용합니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `항목입력`, `견적서` 시트 3개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `QuoteGenerator.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"견적서 자동화"**가 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `항목입력` 시트에 품목을 입력합니다.
2. 메뉴에서 **① 견적서 생성/새로고침**을 누릅니다 → `견적서` 시트가 자동으로 채워집니다.
3. **② PDF로 저장**을 누르면 내 드라이브의 "견적서_PDF" 폴더에 저장됩니다.
4. **③ 이메일로 보내기**를 누르면 받는 사람 이메일만 입력하면 바로 발송됩니다.

## 자주 묻는 질문

**Q. 메뉴가 안 보여요.**
A. 저장 후 시트를 새로고침(F5)했는지 확인하세요. 그래도 안 보이면 Apps Script 편집기에서 `onOpen` 함수를 한 번 직접 실행해보세요.

**Q. "권한이 필요합니다" 경고가 떠요.**
A. 본인 구글 계정 안에서 실행되는 스크립트라서 뜨는 정상적인 안내입니다. "고급 → OOO(안전하지 않음)로 이동 → 허용"을 눌러주시면 됩니다.

**Q. 회사 로고나 도장을 넣고 싶어요.**
A. `견적서` 시트는 자동 생성 후에도 일반 구글시트이므로, 생성 직후 이미지를 수동으로 삽입할 수 있습니다. 단, 메뉴 ①을 다시 누르면 지워지니 PDF 저장 직전에 넣는 걸 권장합니다.
