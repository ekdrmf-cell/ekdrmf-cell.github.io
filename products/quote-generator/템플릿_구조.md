# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 3개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 회사명 | (본인 회사명 입력) |
| 사업자번호 | (000-00-00000) |
| 대표자 | (대표자명) |
| 연락처 | (전화번호) |
| 주소 | (주소) |
| 부가세율 | 0.1 |

- A열은 항목 이름(고정), B열에만 실제 값을 입력합니다.
- "부가세율"은 10%면 `0.1`, 부가세 없음이면 `0`을 입력하세요.

## 시트 2: `항목입력`

1행(맨 위)은 제목 줄로 비워두거나 아래처럼 헤더를 적어두세요. **실제 데이터는 2행부터** 입력합니다.

| A열 (품목) | B열 (규격) | C열 (수량) | D열 (단가) | E열 (비고) |
|---|---|---|---|---|
| 예: 홈페이지 제작 | 반응형 5페이지 | 1 | 800000 | |
| 예: 유지보수 | 월 1회 | 3 | 50000 | 3개월분 |

- 필요한 만큼 아래로 행을 추가하면 됩니다. 빈 행은 자동으로 무시됩니다.
- 수량·단가는 숫자만 입력하세요(쉼표, 원 표시 없이).

## 시트 3: `견적서`

- 이 시트는 **비워두세요**. 스크립트가 실행되면 자동으로 내용을 채웁니다.
- 직접 이 시트에 뭔가를 입력해도 다음에 "① 견적서 생성/새로고침"을 누르면 지워지고 새로 채워집니다.

## 확인 체크리스트

- [ ] 시트 이름 3개(`설정`, `항목입력`, `견적서`)가 정확히 일치하는가
- [ ] `설정` 시트 A열에 항목 이름이 오타 없이 들어있는가 (회사명/사업자번호/대표자/연락처/주소/부가세율)
- [ ] `항목입력` 시트 2행부터 데이터가 있는가
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "견적서 자동화" 메뉴가 보이는가
