# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 3개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 회사명 | (본인 회사명 입력) |
| 사업자번호 | (000-00-00000) |
| 대표자 | (대표자명) |
| 국민연금_근로자요율 | 0.0475 |
| 국민연금_사업주요율 | 0.0475 |
| 국민연금_상한액 | 6370000 |
| 국민연금_하한액 | 400000 |
| 건강보험_근로자요율 | 0.03595 |
| 건강보험_사업주요율 | 0.03595 |
| 장기요양보험_요율 | 0.1295 |
| 고용보험_근로자요율 | 0.009 |
| 고용보험_사업주요율 | 0.0115 |
| 기준연도 | 2026 |

- A열은 항목 이름(고정), B열에만 실제 값을 입력합니다.
- 위 숫자는 **2026년 기준** 요율입니다. 4대보험 요율은 매년(국민연금은 매년 7월) 바뀌므로, 새해가 되면 국민연금공단·건강보험공단 공지를 보고 이 표의 숫자만 바꿔주면 계속 정확하게 씁니다.
- 고용보험 사업주요율은 회사 규모·업종에 따라 다릅니다(150인 미만 일반 기업 기준 1.15%로 기본값을 넣어뒀습니다). 정확한 우리 회사 요율은 근로복지공단 토탈서비스에서 확인해 바꿔주세요.
- 산재보험은 전액 사업주 부담이고 업종별로 요율 차이가 아주 커서(0.7%~34%) 이 템플릿에서는 자동계산하지 않습니다. 근로복지공단 사이트에서 우리 회사 업종코드로 직접 확인하세요.

## 시트 2: `직원정보`

1행(맨 위)은 아래처럼 헤더를 적어두세요. **실제 데이터는 2행부터** 입력합니다.

| A열 (성명) | B열 (기본급) | C열 (상여금 등 과세수당) | D열 (비과세수당) | E열 (소득세) | F열 (이메일) | G열 (부양가족수, 참고용) |
|---|---|---|---|---|---|---|
| 예: 김철수 | 3000000 | 200000 | 200000 | 84850 | kim@example.com | 2 |

- **E열(소득세)은 자동계산이 아니라 직접 입력하는 칸입니다.** 아래 "소득세는 왜 직접 입력하나요?" 항목을 꼭 읽어주세요.
- D열 비과세수당은 식대(최대 20만원) 등 세금이 붙지 않는 항목의 합계입니다. 없으면 0을 입력하세요.
- 필요한 만큼 아래로 행을 추가하면 됩니다.

## 시트 3: `급여명세서`

- B1 칸에 `직원정보` 시트에 입력한 성명 중 하나를 선택합니다(데이터 유효성 드롭다운으로 자동 설정됩니다. 안 뜨면 아래 체크리스트의 드롭다운 설정 방법을 따라하세요).
- 나머지 칸은 **비워두세요**. 메뉴에서 "① 급여명세서 생성/새로고침"을 누르면 선택한 직원의 명세서가 자동으로 채워집니다.

## 드롭다운(데이터 유효성) 설정 방법 — 최초 1회만

1. `급여명세서` 시트의 B1 셀을 클릭합니다.
2. 상단 메뉴 [데이터 → 데이터 확인]을 클릭합니다.
3. 조건을 "범위의 값"으로 선택하고, 범위에 `직원정보!A2:A100`을 입력합니다.
4. 저장하면 B1 셀에 드롭다운 화살표가 생겨서 등록된 직원 이름 중 하나를 고를 수 있습니다.

## 소득세는 왜 직접 입력하나요?

근로소득세는 국세청이 매달 발표하는 "근로소득 간이세액표"를 급여액·부양가족수 기준으로 조회해서 정합니다. 이 표는 만 원 단위 구간마다 수천 줄이 넘고 해마다 개정되는 공식 자료라서, 템플릿 안에 베껴 넣으면 오히려 틀린 세금을 계산할 위험이 있습니다. 그래서 이 템플릿은 **정확한 공식으로 계산 가능한 4대보험은 자동으로 계산하고, 소득세만 아래 국세청 공식 조회 화면에서 직접 확인해서 입력**하도록 설계했습니다. 이 방법이 훨씬 안전합니다.

1. [국세청 홈택스 근로소득 간이세액표 조회](https://teht.hometax.go.kr/websquare/websquare.html?w2xPath=/ui/sf/a/a/UTESFAAF99.xml)에 접속합니다.
2. 월급여액과 공제대상 가족수(본인 포함)를 입력하고 조회합니다.
3. 나온 소득세 금액을 `직원정보` 시트 E열에 그대로 입력합니다.
4. 지방소득세(소득세의 10%)는 템플릿이 자동으로 계산해줍니다.

## 확인 체크리스트

- [ ] 시트 이름 3개(`설정`, `직원정보`, `급여명세서`)가 정확히 일치하는가
- [ ] `설정` 시트 A열에 항목 이름이 오타 없이 들어있는가
- [ ] `직원정보` 시트 2행부터 직원 데이터가 있는가 (소득세 E열 포함)
- [ ] `급여명세서` 시트 B1에 드롭다운을 설정했는가
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "급여명세서 자동화" 메뉴가 보이는가
