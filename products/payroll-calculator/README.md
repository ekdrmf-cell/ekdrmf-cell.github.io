# 급여명세서 자동계산기

직원 이름과 기본급만 입력하면 국민연금·건강보험·장기요양보험·고용보험을 자동으로 계산해서 급여명세서를 만들어주고, PDF 저장과 이메일 발송까지 버튼 하나로 끝나는 구글시트 템플릿입니다. 직원이 여러 명이면 전체 직원에게 한 번에 발송할 수도 있습니다.

## 무엇이 자동화되나요

- 직원정보(기본급/상여금/비과세수당)를 표에 입력하면 4대보험(국민연금·건강보험·장기요양보험·고용보험)을 정확한 공식으로 자동 계산합니다.
- 실수령액(차인지급액)까지 자동으로 나옵니다.
- 완성된 급여명세서를 클릭 한 번으로 PDF 저장하거나, 해당 직원에게 바로 이메일 발송할 수 있습니다.
- 직원이 여러 명이면 "전체 직원 일괄 이메일 발송" 버튼 하나로 전 직원에게 각자의 명세서를 따로따로 보낼 수 있습니다.
- 4대보험 요율은 `설정` 시트에 모아뒀기 때문에, 해마다 요율이 바뀌어도 숫자만 바꾸면 계속 정확하게 씁니다.

## 소득세는 자동계산이 아닙니다 (안전을 위한 설계)

근로소득세는 국세청이 매달 발표하는 "간이세액표"라는 공식 조견표를 급여·부양가족수 기준으로 조회해서 정하는데, 이 표는 구간이 수천 줄이 넘고 매년 개정됩니다. 그래서 이 템플릿은 **정확한 공식으로 계산되는 4대보험만 자동화하고, 소득세는 국세청 공식 조회 화면에서 확인한 금액을 직접 입력**하도록 만들었습니다. 조회는 1분이면 끝나고, 이렇게 하는 게 잘못된 세금을 계산하는 것보다 훨씬 안전합니다. (지방소득세는 소득세의 10%이므로 자동 계산됩니다.)

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `직원정보`, `급여명세서` 시트 3개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `PayrollCalculator.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"급여명세서 자동화"**가 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `직원정보` 시트에 직원별 기본급·상여금·비과세수당·소득세(국세청 조회값)·이메일을 입력합니다.
2. `급여명세서` 시트 B1에서 직원 이름을 선택합니다.
3. 메뉴에서 **① 급여명세서 생성/새로고침**을 누릅니다 → 명세서가 자동으로 채워집니다.
4. **② PDF로 저장**을 누르면 내 드라이브의 "급여명세서_PDF" 폴더에 저장됩니다.
5. **③ 이메일로 보내기**를 누르면 해당 직원 이메일로 바로 발송됩니다.
6. 직원이 여러 명이면 **④ 전체 직원 일괄 이메일 발송**을 누르면 등록된 모든 직원에게 각자의 명세서가 자동으로 발송됩니다.

## 자주 묻는 질문

**Q. 계산된 4대보험 금액이 실제와 조금 달라요.**
A. `설정` 시트의 요율·상한액·하한액이 최신인지 확인하세요. 국민연금은 매년 7월, 건강보험은 매년 1월에 요율이 바뀝니다. 회사의 고용보험 사업주요율은 업종·규모에 따라 다르니 근로복지공단에서 정확한 값을 확인해 넣어주세요.

**Q. 소득세를 자동으로 계산해줄 수는 없나요?**
A. 위 "소득세는 자동계산이 아닙니다" 항목을 참고하세요. 국세청 조회는 [이 링크](https://teht.hometax.go.kr/websquare/websquare.html?w2xPath=/ui/sf/a/a/UTESFAAF99.xml)에서 월급여액과 부양가족수만 넣으면 1분 안에 확인됩니다.

**Q. 산재보험료도 포함되나요?**
A. 산재보험은 전액 사업주 부담이고 업종별 요율 차이가 커서(0.7%~34%) 이 템플릿에는 포함하지 않았습니다. 근로복지공단 토탈서비스에서 업종코드로 확인하세요.

**Q. 회사 로고를 넣고 싶어요.**
A. `급여명세서` 시트는 자동 생성 후에도 일반 구글시트이므로, 생성 직후 이미지를 수동으로 삽입할 수 있습니다. 단, 메뉴 ①을 다시 누르면 지워지니 PDF 저장 직전에 넣는 걸 권장합니다.
