# 회원권·정기결제 만료 자동알림 시트

회원의 시작일·종료일만 입력하면 만료가 임박했거나 이미 지난 회원을 자동으로 찾아 색깔로 표시하고, 관리자에게 요약 이메일로, 회원 본인에게는 갱신 안내 이메일로 각각 알려주는 구글시트 템플릿입니다. 헬스장·필라테스·네일샵·학원·공방처럼 기간제 회원권을 운영하는 업종에 맞게 만들었습니다.

## 무엇이 자동화되나요

- 회원 종료일만 입력하면 오늘 기준 남은 일수를 자동 계산합니다.
- 만료가 임박한 회원(기준일수는 직접 설정 가능, 기본 7일)은 노란색, 이미 지난 회원은 빨간색으로 자동 표시됩니다.
- 관리자에게 "임박/만료 회원 몇 명" 요약 이메일을 보낼 수 있습니다(매일 자동 발송 설정도 가능).
- 임박/만료 회원 본인에게는 각자 다른 문구로 갱신 안내 이메일을 한 번에 보낼 수 있습니다.
- 회원현황을 PDF로도 저장할 수 있습니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `회원정보`, `회원현황` 시트 3개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `MembershipExpiryAlert.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"회원만료 자동알림"**이 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `회원정보` 시트에 회원별 회원권종류·시작일·종료일을 입력합니다.
2. 메뉴에서 **① 회원현황 새로고침**을 누르면 임박/만료 회원이 색깔로 표시됩니다.
3. **② 회원현황 PDF로 저장**을 누르면 내 드라이브의 "회원현황_PDF" 폴더에 저장됩니다.
4. **③ 관리자에게 요약 이메일 발송**을 누르면 임박/만료 회원 명단이 정리돼서 관리자 이메일로 갑니다.
5. **④ 임박/만료 회원에게 개별 갱신안내 발송**을 누르면 이메일이 등록된 회원 각자에게 맞춤 안내 메일이 자동 발송됩니다.
6. 매일 자동으로 관리자 요약 알림을 받고 싶다면 `템플릿_구조.md` 맨 아래 트리거 설정 방법을 따라하세요(5분).

## 자주 묻는 질문

**Q. 카카오 알림톡으로 보낼 수는 없나요?**
A. 이 템플릿은 구글 계정만 있으면 바로 되는 이메일 발송까지만 기본 포함했습니다. 카카오 알림톡은 알리고·Solapi 같은 별도 유료 서비스 가입과 발신 프로필 등록이 필요해서, 필요하신 경우 별도로 연동을 고려해보시길 권합니다.

**Q. 종료일을 입력했는데 계산이 안 돼요.**
A. `회원정보` 시트 E열이 진짜 날짜 형식인지 확인하세요. 텍스트로 "2026.9.1"처럼 입력하면 인식이 안 될 수 있습니다.

**Q. 정기결제(구독) 회원도 쓸 수 있나요?**
A. 네, 매달 결제일을 "종료일"에 넣고 결제가 갱신될 때마다 종료일을 다음 달로 수정해주면 동일하게 작동합니다.
