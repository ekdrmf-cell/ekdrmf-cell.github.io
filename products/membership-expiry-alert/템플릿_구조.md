# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 3개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 회사명 | (본인 매장/업체명 입력) |
| 알림받을이메일 | (관리자가 요약 알림을 받을 이메일) |
| 임박기준일수 | 7 |

- "임박기준일수"는 만료일이 며칠 이내로 남았을 때 "임박"으로 표시할지 정하는 숫자입니다. 7이면 만료 7일 전부터 노란색으로 경고 표시됩니다.

## 시트 2: `회원정보`

1행은 헤더로 두고, **실제 데이터는 2행부터** 입력합니다.

| A열 (성명) | B열 (연락처) | C열 (회원권종류) | D열 (시작일) | E열 (종료일) | F열 (이메일) | G열 (비고) |
|---|---|---|---|---|---|---|
| 예: 김수영 | 010-0000-0000 | 3개월 회원권 | 2026-06-01 | 2026-09-01 | kim@example.com | |

- D열·E열은 반드시 날짜 형식으로 입력하세요(셀을 클릭하고 달력에서 고르거나 `2026-09-01` 형식으로 직접 입력).
- 회원이 새로 등록하거나 갱신할 때마다 이 시트에 한 줄씩 추가/수정하면 됩니다.

## 시트 3: `회원현황`

- 이 시트는 **비워두세요**. 메뉴에서 "① 회원현황 새로고침"을 누르면 자동으로 채워집니다.
- 종료일까지 남은 일수를 계산해서 "정상"(흰색) / "임박"(노란색) / "만료"(빨간색)으로 표시됩니다.

## 확인 체크리스트

- [ ] 시트 이름 3개(`설정`, `회원정보`, `회원현황`)가 정확히 일치하는가
- [ ] `설정` 시트에 임박기준일수가 숫자로 들어있는가
- [ ] `회원정보` 시트 D열·E열이 진짜 날짜 형식인가(텍스트로 입력하면 계산이 안 됩니다)
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "회원만료 자동알림" 메뉴가 보이는가

## 매일 자동으로 알림받고 싶다면 (선택, 5분)

1. 상단 메뉴 [확장 프로그램 → Apps Script]를 엽니다.
2. 왼쪽 시계 모양 아이콘(트리거)을 클릭합니다.
3. 오른쪽 아래 "+ 트리거 추가"를 누릅니다.
4. 실행할 함수는 `emailAdminSummary`를 선택하고, 이벤트 소스는 "시간 기반", 시간 간격 유형은 "일 타이머"를 선택한 뒤 원하는 시간대를 고릅니다.
5. 저장하면 그날부터 매일 그 시간에 자동으로 관리자에게 만료임박/만료 회원 요약 이메일이 발송됩니다.
