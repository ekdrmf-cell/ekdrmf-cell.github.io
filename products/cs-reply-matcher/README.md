# CS 자주문의 · 리뷰 답글 자동매칭 시트

고객 문의 내용이나 리뷰 별점만 입력하면, 미리 등록해둔 규칙에서 가장 알맞은 답변을 찾아 자동으로 완성해주는 구글시트 템플릿입니다. 매번 비슷한 답을 새로 타이핑할 필요가 없습니다.

## 무엇이 자동화되나요

- 고객 문의 내용을 붙여넣으면 키워드를 분석해서 가장 알맞은 FAQ 답변을 찾아줍니다(배송조회·교환환불·사이즈문의 등 원하는 유형을 자유롭게 등록).
- 리뷰 별점(1~5)과 리뷰 내용을 입력하면 별점·키워드에 맞는 답글을 자동으로 만들어줍니다.
- 답변에 고객명·상품명을 자동으로 채워 넣어서 붙여넣기만 하면 되는 상태로 완성해줍니다.
- 오늘 처리한 CS·리뷰 응대 이력이 자동으로 쌓이고, PDF 저장·이메일 발송도 됩니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `FAQ규칙`, `리뷰답글규칙`, `처리이력` 시트 4개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `CsReplyMatcher.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"CS·리뷰 자동응답"**이 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `FAQ규칙`·`리뷰답글규칙` 시트에 자주 받는 질문·리뷰 유형과 답변 문구를 최대한 다양하게 등록해둡니다(많이 등록해둘수록 매칭 성공률이 올라갑니다).
2. 새 문의가 오면 메뉴에서 **① FAQ 답변 찾기**를 누르고 문의 내용을 붙여넣으면 답변 초안이 뜹니다.
3. 새 리뷰가 달리면 **② 리뷰 답글 만들기**를 누르고 별점·리뷰 내용을 입력하면 답글 초안이 뜹니다.
4. 뜬 답변을 복사해서 스마트스토어·배달앱 등의 답변창에 붙여넣으면 끝입니다.
5. 하루 마무리할 때 **③ 오늘 처리이력 PDF로 저장**, **④ 오늘 처리이력 이메일로 보내기**로 그날 처리 내역을 보관할 수 있습니다.

## 자주 묻는 질문

**Q. "일치하는 답변이 없습니다"가 자꾸 떠요.**
A. 그 유형의 질문·리뷰가 처음 나온 것입니다. 직접 답변한 뒤 `FAQ규칙`이나 `리뷰답글규칙`에 그 유형을 새로 등록해두면 다음부터는 자동으로 나옵니다. 계속 쓰다 보면 매칭 성공률이 점점 올라갑니다.

**Q. 여러 플랫폼(스마트스토어·쿠팡·배달앱)에 자동으로 답변이 올라가나요?**
A. 아닙니다. 이 템플릿은 "답변 문구를 빠르게 완성"해주는 도구이고, 실제로 각 플랫폼에 입력하는 것은 직접 복사해서 붙여넣어야 합니다. 플랫폼마다 API 연동은 불안정하고 정책 변경 위험이 있어 이 방식이 더 안전합니다.

**Q. 답변 톤(존댓말, 이모지 등)을 바꾸고 싶어요.**
A. `FAQ규칙`·`리뷰답글규칙`의 템플릿 문구를 원하는 톤으로 직접 수정하면 됩니다.
