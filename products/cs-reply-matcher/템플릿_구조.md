# 구글시트 칸 구조 (직접 만들 때 그대로 따라하세요)

구글시트에서 하단 탭에 시트 4개를 만들고, 시트 이름을 정확히 아래와 똑같이 지어주세요. **이름이 한 글자라도 다르면 스크립트가 시트를 못 찾습니다.**

## 시트 1: `설정`

| A열 | B열 |
|---|---|
| 사업체명 | (본인 사업체명 입력) |
| 서명 | (답변 끝에 붙일 문구, 예: 고객만족팀 드림) |
| 로그받을이메일 | (하루치 처리이력을 받아볼 이메일, 없으면 비워둬도 됨) |

## 시트 2: `FAQ규칙`

1행은 헤더, **실제 데이터는 2행부터** 입력합니다. 자주 받는 질문 유형별로 한 줄씩 등록하세요.

| A열 (키워드) | B열 (질문유형) | C열 (답변템플릿) |
|---|---|---|
| 배송,언제,도착 | 배송조회 | 안녕하세요 {고객명}님, 주문하신 {상품명}은(는) 결제 완료 후 1~2일 내 출고됩니다. 송장번호는 출고 시 문자로 안내드립니다. |
| 교환,환불,반품 | 교환환불 | 안녕하세요 {고객명}님, 교환·환불은 상품 수령 후 7일 이내 가능합니다. 주문번호와 사유를 함께 남겨주시면 빠르게 도와드리겠습니다. |
| 사이즈,크기,치수 | 사이즈문의 | 안녕하세요 {고객명}님, {상품명} 상세페이지의 사이즈표를 참고해주세요. 추가로 궁금한 점 있으면 말씀해주세요. |

- **A열(키워드)**은 쉼표로 여러 개를 구분해서 넣으세요. 고객 문의 내용에 이 키워드 중 하나라도 포함되면 그 규칙이 후보가 됩니다(여러 키워드가 겹치면 더 많이 일치하는 규칙을 우선 보여줍니다).
- **C열(답변템플릿)**에 `{고객명}`, `{상품명}`을 넣으면 실행할 때 입력한 값으로 자동 치환됩니다(비워두고 실행해도 됨).

## 시트 3: `리뷰답글규칙`

1행은 헤더, **실제 데이터는 2행부터** 입력합니다.

| A열 (별점) | B열 (키워드, 선택) | C열 (답글템플릿) |
|---|---|---|
| 5 | | {고객명}님, 소중한 5점 리뷰 감사합니다! 앞으로도 좋은 모습 보여드리겠습니다. |
| 4 | | {고객명}님, 좋은 평가 감사합니다. 더 나은 서비스로 보답하겠습니다. |
| 3 | | {고객명}님, 리뷰 남겨주셔서 감사합니다. 아쉬운 점이 있으셨다면 편하게 문의 남겨주세요. |
| 2 | 배송 | {고객명}님, 배송 관련 불편을 드려 죄송합니다. 더 신경쓰겠습니다. |
| 1 | 불량,파손 | {고객명}님, 불편을 드려 대단히 죄송합니다. 교환·환불 도와드리겠습니다. 문의 남겨주시면 바로 처리하겠습니다. |

- **A열(별점)**은 1~5 중 숫자 하나만 입력하세요.
- **B열(키워드)**은 선택입니다. 비워두면 그 별점에 해당하는 "기본 답글"이 되고, 키워드를 적으면(예: "배송,포장") 리뷰 내용에 그 단어가 있을 때만 이 규칙이 우선 사용됩니다.
- 같은 별점에 "키워드 있는 규칙"과 "키워드 없는 기본 규칙"을 같이 등록해두면, 키워드가 맞을 때는 그 규칙을, 안 맞으면 기본 규칙을 자동으로 씁니다.

## 시트 4: `처리이력`

- 이 시트는 **비워두세요**. FAQ 답변이나 리뷰 답글을 만들 때마다 자동으로 한 줄씩 기록이 쌓입니다.

## 확인 체크리스트

- [ ] 시트 이름 4개(`설정`, `FAQ규칙`, `리뷰답글규칙`, `처리이력`)가 정확히 일치하는가
- [ ] `FAQ규칙`·`리뷰답글규칙`에 자주 받는 질문/리뷰 유형을 충분히 등록했는가(등록 안 된 유형은 매칭이 안 됩니다)
- [ ] Apps Script를 저장한 뒤 시트를 새로고침해서 "CS·리뷰 자동응답" 메뉴가 보이는가

## 사용 팁

이 도구는 매번 새 문의·리뷰가 올 때마다 메뉴를 눌러서 즉석으로 답변을 만드는 용도입니다. 처음에 FAQ·리뷰답글 규칙을 최대한 다양하게 채워둘수록 매칭 성공률이 올라갑니다. 매칭되는 규칙이 없으면 "일치하는 답변 없음"이라고 알려주니, 그럴 때는 직접 답변한 뒤 그 유형을 규칙에 새로 추가해두면 다음부터는 자동으로 나옵니다.
