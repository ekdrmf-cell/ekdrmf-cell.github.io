# 재고 부족 자동알림 + 입출고 관리 시트

입고/출고만 기록하면 품목별 현재 재고를 자동으로 계산하고, 미리 정해둔 최소재고보다 부족해진 품목이 있으면 이메일로 바로 알려주는 구글시트 템플릿입니다.

## 무엇이 자동화되나요

- 입고/출고 내역만 기록하면 품목별 현재재고가 자동으로 계산됩니다(직접 재고를 세거나 계산할 필요 없음).
- 최소재고 기준보다 부족한 품목은 재고현황 표에서 빨간색으로 자동 표시됩니다.
- 부족한 품목이 있으면 클릭 한 번으로, 혹은 매일 자동으로 담당자 이메일에 목록이 발송됩니다.
- 재고현황을 PDF로도 저장할 수 있습니다.
- 품목이 몇 개든, 입출고 기록이 몇 줄이든 그대로 반영됩니다.

## 설치 방법 (5분)

1. [Google Sheets](https://sheets.google.com)에서 새 스프레드시트를 만듭니다.
2. `템플릿_구조.md` 파일을 열어 안내대로 `설정`, `품목마스터`, `입출고기록`, `재고현황` 시트 4개를 만들고 값을 채웁니다.
3. 시트 상단 메뉴에서 **확장 프로그램 → Apps Script**를 클릭합니다.
4. `InventoryAlert.gs` 파일 내용을 전부 복사해서 붙여넣고 저장합니다(Ctrl+S 또는 💾 아이콘).
5. 구글시트 탭으로 돌아와 새로고침하면 상단 메뉴에 **"재고 자동알림"**이 생깁니다.
6. 처음 실행할 때 구글이 권한 승인을 요청합니다 — 본인 계정이니 "고급 → 이동" 후 허용해주세요.

## 사용 방법

1. `품목마스터` 시트에 품목별 최소재고기준·초기재고를 입력합니다.
2. 물건이 들어오거나 나갈 때마다 `입출고기록` 시트에 한 줄씩 추가합니다(입고/출고 구분).
3. 메뉴에서 **① 재고현황 새로고침**을 누르면 품목별 현재재고와 부족 여부가 표로 나옵니다.
4. **② 재고현황 PDF로 저장**을 누르면 내 드라이브의 "재고현황_PDF" 폴더에 저장됩니다.
5. **③ 재고부족 알림 이메일 발송**을 누르면 부족한 품목만 정리해서 이메일로 바로 보냅니다(부족한 게 없으면 발송하지 않습니다).
6. 매일 정해진 시간에 자동으로 알림받고 싶다면 `템플릿_구조.md` 맨 아래 "매일 자동으로 알림받고 싶다면" 항목을 따라 트리거를 설정하세요(5분).

## 자주 묻는 질문

**Q. 품목이 100개, 200개가 넘어도 되나요?**
A. 됩니다. `품목마스터`와 `입출고기록` 시트에 행을 계속 추가하면 그만큼 늘어난 데이터를 그대로 계산합니다.

**Q. 입출고기록에 오타를 냈어요.**
A. 해당 줄을 수정하고 다시 "① 재고현황 새로고침"을 누르면 바로 반영됩니다.

**Q. 여러 매장(지점)의 재고를 따로 관리하고 싶어요.**
A. 지점별로 구글시트 파일을 따로 만들어 쓰는 것을 권장합니다(한 파일 안에서 지점을 나누면 계산이 꼬일 수 있습니다).

**Q. 자동 이메일이 매일 오지 않아요.**
A. Apps Script의 "트리거" 설정이 빠졌을 수 있습니다. `템플릿_구조.md`의 트리거 설정 방법을 다시 확인해주세요.
